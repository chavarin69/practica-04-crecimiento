Cuestionario Práctica 04

¿Qué tema representa tu simulador de crecimiento?

Representa un visor educativo botánico enfocado en el ciclo de vida del Agave tequila variedad azul, mostrando sus etapas de desarrollo (Piña -> Pencas -> Quiote).

¿Cómo implementaste el bucle de animación con requestAnimationFrame?

Creé la función animate() que se llama a sí misma recursivamente. Utilicé THREE.Clock para obtener el delta (tiempo entre frames) y así independizar la velocidad de la animación, sumando ese delta a mis propias variables currentGrowthTime y currentWindTime.

¿Cómo animaste el crecimiento de la planta? (escala, posición, rotación)

Modificando la propiedad .scale de los objetos en 3 fases secuenciales. Utilicé las funciones matemáticas Math.min y Math.max para interpolar el tamaño desde (0.001) hasta (1,1,1) de forma suave, ajustando previamente el punto de anclaje con .translate para que brotaran desde el suelo.

¿Cómo simulaste el viento? ¿Usaste shaders o transformaciones simples?

Utilicé transformaciones simples matemáticas en JavaScript. Apliqué una función Math.sin(currentWindTime) sobre el eje Z de rotación de cada penca, aplicando un pequeño offset basado en el índice del arreglo para que las hojas se movieran de forma orgánica y desfasada.

¿Qué controles agregaste para modificar la simulación?

Agregué una interfaz HTML superpuesta conectada mediante EventListeners. Incluye sliders de velocidad y viento, y botones para pausar/reanudar tiempos, reiniciar el modelo, simular sequía (cambio de material) y reiniciar la cámara.

¿Cómo gestionaste la jerarquía para que el crecimiento se propague?

Creé un grupo general agaveGroup. Dentro metí la Piña, el Quiote y un subgrupo pencasGroup. Al escalar pencasGroup, todas las hojas crecen simultáneamente desde sus posiciones ancladas.

¿Qué shader personalizado usaste (si aplica) y qué efecto produce?

No aplica, la simulación de movimiento y físicas orgánicas se realizó íntegramente mediante transformaciones matemáticas en el Main Thread (JavaScript).

¿Qué parte del proyecto fue la más difícil?

Ajustar los pivotes de las geometrías (como desplazar la esfera de la piña con translate) para que al escalar desde cero, la planta brotara visualmente desde el nivel del suelo (y=0) y no se encogiera hacia su centro geométrico flotando en el aire.

¿Cómo podrías mejorar este simulador si lo conectaras después con PHP, FlightPHP y SQLite?

Podría crear una base de datos SQLite con un catálogo de distintas especies de plantas (Ej. Agave Espadín, Salmiana). FlightPHP serviría como API REST para que mi frontend consulte los parámetros específicos de cada especie (tiempo de maduración, colores, altura máxima) e inyecte esos datos al main.js dinámicamente.
